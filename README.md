# delaram-portfolio

Personal portfolio website of Delaram Moradi, with a dark, galaxy-inspired theme.

## Pages

- Home
- Projects
- Trainings
- Experience
- Connect

## Development

```sh
git clone <this-repository-url>
cd delaram-portfolio
npm i
npm run dev
```
